# Bot de Filas Discord

Sistema próprio de filas para Discord, inspirado em funcionalidades comuns de bots profissionais de filas.

## Recursos
- múltiplas filas;
- formatos 1x1 a 5x5;
- entrada/saída por botões;
- painel atualizado;
- criação automática de partidas;
- threads para partidas;
- mediadores;
- perfil e ranking;
- blacklist;
- abrir/fechar/resetar filas;
- SQLite persistente.

## Instalação
1. Node.js 20+
2. npm install
3. copie .env.example para .env
4. preencha DISCORD_TOKEN, CLIENT_ID e GUILD_ID
5. npm run register
6. npm start

O bot precisa dos scopes bot e applications.commands.

A implementação é própria e não copia código, marca ou ativos proprietários de terceiros.
